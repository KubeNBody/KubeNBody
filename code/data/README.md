# Example initial conditions

Input files in the simulator's CSV format: `n,idBody,m,x,y,z,vx,vy,vz`, in units with G = 1.
They were generated by the KubeNBody authors and are distributed under the project's licence.

| File | Bodies | Model |
|---|---|---|
| `gali.txt` | 1,001 | Disc of 1,000 equal-mass bodies (m = 1,000) around a central mass of 10^6 |
| `demo/*.csv` | 3 to 602 | The dashboard demo's jobs, generated by `scripts/make_demo_inputs.py`: the figure-eight, moth I, yin-yang 1a and goggles three-body orbits, and two colliding disc galaxies |
